# Instructions for AI coding agents

This repository is public. Keep it free of personal and customer data.

## Commits and pull requests

- Author and commit as the repository owner only:
  `usrnmhcs5he <170802491+usrnmhcs5he@users.noreply.github.com>`.
  Set it before the first commit in a fresh clone:

  ```bash
  git config user.name usrnmhcs5he
  git config user.email 170802491+usrnmhcs5he@users.noreply.github.com
  git config commit.gpgsign false
  ```

- Never commit as `Claude <noreply@anthropic.com>` or any other AI, bot or tool identity,
  and never add `Co-Authored-By`, `Generated by`/`Generated with`, session links or similar
  attribution lines to commit messages, pull request titles or descriptions.
- Before pushing, check: `git log --format='%an <%ae> | %cn <%ce>%n%b' origin/main..HEAD`
  must show only the owner identity and no attribution trailers.

## Data hygiene

- No customer domains, host names, IP addresses, subnets, tenant names, credentials, tokens,
  user names or local paths in code, defaults, examples, tests or sample files.
- Use `example.com`, `example.net`, `example.org`, `tenant.onmicrosoft.com` and the
  documentation IP ranges (192.0.2.0/24, 198.51.100.0/24, 203.0.113.0/24, 2001:db8::/32).
- Real domain lists (`domains.txt`) and reports (`output/`) are git-ignored and stay that way.
